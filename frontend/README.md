# 满天星 · Vue 前端

- `src/`：页面、共享组件、样式。
- `public/`：Tabler 预编译资源、许可证与图标；由 Node 静态路由提供。
- `test/`、`playwright.config.js`：浏览器测试，使用临时后端数据库。
- `dist/`、`node_modules/`、`test-results/`：生成目录，Git 忽略。

本目录 `npm ci && npm run build` 编译前端。通常直接从项目根执行统一 npm 命令；开发时使用根目录 `npm run dev` 启动同域 Express + Vite，不单独运行裸 Vite 服务器。

本目录 `npm run test:e2e` 自动编译并启动临时后端测试服务，不改变真实工作区账号/数据。

设备工具栏「当前设备」卡保持 34px 高，数字与标签垂直居中；`test/ui-fidelity.spec.js` 校验桌面、窄窗口、明暗主题和空列表的居中效果。

顶栏独立适配视口：小于 1280px 时收起搜索与昨日统计，扩宽后恢复；小于等于 940px 时收起整组日期统计，账号只保留头像和名称（82–140px、长名称省略）；角色、APK ID 与有效期保留在完整 title 和账号详情页中，扩宽后恢复。顶栏取消 800px 最小宽度，在 550–940px 窄桌面窗口中仍完整显示账号和三个 34×34px 图标工具。表格继续使用桌面最小画布与横向滚动，设备行高保持 85 CSS px。比较截图时请使用相同浏览器缩放比例。

统计区按参考布局居中，在线/总数使用 15px 数字、日期指标使用 13px 数字；侧栏本地 SVG 使用灰色及选中紫蓝色。保留本项目品牌、数据、菜单和按钮行为。

设备列表底栏为 45px：总数与紧凑页码居中，单页不显示前后翻页箭头；多页支持页码、上一页/下一页及键盘操作。短列表留白撑满视口，底栏固定在侧栏右侧、横向滚动时保持可见；长列表保留页面滚动并预留底栏高度，不遮挡最后一行。选中数量只在左侧按需显示，示例标记留在对应设备行。`test/footer-pagination.spec.js` 覆盖空列表、刷新、多页、明暗主题和窄窗口。

顶栏工具保留真实操作：主题按钮切换明暗并保存偏好；WS 状态入口沿用现有协议审计（普通账号显示状态）；退出按钮调用现有退出接口，成功后回到登录，失败时保留会话并显示错误，会话变化时清除旧错误。按钮使用可访问名称与键盘焦点，`test/header-tools.spec.js` 覆盖主题、协议跳转、退出、失败重试。

主侧栏按最新参考补齐：设备、用户、AI、注入、构建、推送、拉黑、性能、翻译，超管另保留日志；总台不显示日志，子账号显示设备/注入/构建/推送。用户复用原账号管理页，性能保留待接入状态页，AI、注入与推送使用独立界面预览，入口可键盘访问。`/blacklist` 使用独立紧凑表格与工具栏，复用当前账号可见设备缓存及原解除拉黑接口，仅保留严格布尔已拉黑记录；服务端搜索、白名单排序与本地翻页保持该页面，单行/选中释放成功后记录移出。普通设备页的既有筛选保持不变。

新增页面同时登记在 Node 生产 SPA 路由白名单，支持直接访问与刷新；根设备页的 `blacklisted=1` URL 筛选可以清除，独立拉黑页仍保持模式。`test/sidebar-navigation.spec.js` 覆盖真实刷新、角色守卫、取消拉黑与矮窗口独立侧栏滚动。

单列配置页使用共享 `settings-page--centered`：AI 配置、性能状态页、翻译设置、账号设置、推送面板在侧栏右侧的主内容画布居中；容器最大 810px，保留 30px 左右内距，标题、提示和 750px 卡片同边对齐。窄窗口继续使用 1280px 桌面画布及横向滚动；账号双卡保持等宽。注入模板网格、用户管理、构建双列、服务器日志与记录表保持宽布局。`test/settings-centering.spec.js` 覆盖明暗主题、1920/1440/1280/800px、真实跳转、错误重试及宽页面回归。

`/ai` 当前为 UI-only 配置页：五个提供商、连接参数、提示词、分析参数、策略、锁定权限和高级参数完整展示；可切换提供商、编辑页面草稿、恢复默认提示词及展开高级参数。验证密钥/保存配置/删除配置显示待接入反馈；密钥仅在当前组件内存中，离开或刷新后复位，不写浏览器存储。验证/保存日期与已保存密钥显示当前空状态，不复制参考截图的凭证或时间。页面不发送 AI/短信/设备指令，不触发外部请求或计费；原角色守卫保留。`test/ai-settings.spec.js` 覆盖交互、零业务请求、草稿复位和配置页几何。

## 注入模板界面预览（2026-10-09）

`/injection` 展示四步模板预览流程、45 个地区的九列卡片与应用模板分组弹窗，采用参考图的宽布局、细边框和内部滚动。列表只使用项目合成示例应用与 `com.example.preview.*` 标识，卡片计数代表演示草稿，不是实际启用设备或第三方应用。

超管显示「新增模板」「编辑」入口，可在组件内存中预览新增、编辑及开关变化；总台和子账号只读，开关禁用且无编辑入口。子账号新增注入菜单和已登录只读路由；其余管理页及日志权限不变。刷新重置演示草稿，离开或页面刷新后不保留；保存按钮明确提示接口待接入。原生 dialog 支持独立滚动、Escape、背景关闭与焦点恢复。

本轮仅 UI，不新增后端路由、数据库、设备命令或模板执行能力；不上传页面、脚本或其它执行内容。后续真实存储与管理员写入接口需独立实施服务端角色校验。

推送页 `/push` 按最新要求复用统一居中的 750px 设置列，标题、说明、分组卡片与底部操作同边对齐，保留卡片内文字左对齐、白色圆角卡片与右侧开关；所有已登录角色均可进入自己的绑定与通知偏好界面。超管预留总台机器人配置，总台预留子台机器人配置，子台没有管理入口。通知展示登录提醒、设备状态、构建结果、任务结果和系统公告。账号创建弹窗同时预留专属机器人草稿区，保持原账号提交白名单不变。此阶段不创建机器人、不绑定 Telegram、不发送或保存偏好；所有草稿只保留组件内存，离开/刷新后复位。默认状态为未绑定、待接入，无虚构绑定码或成功记录。

拉黑页列为设备 ID、品牌/型号、最后 IP、账号、备注、原因、操作人、拉黑时间与操作；当前数据接口没有提供的审计/IP字段显示「—」，不从登记时间或当前登录人推测。工具栏含总数、范围说明、搜索、刷新及释放选中数量。选择限当前页；刷新、页码或查询变化后剔除不可见选择。释放复用严格布尔 PATCH，确认取消不发请求，批量失败保留失败项并报告实际成功/失败数量，不新增删除或设备指令。

## 设备详情预览（2026-10-10）

右侧工具栏由 `DeviceRightTools.vue` 延续参考的五组十四按钮，保持 176px 栏宽、34px 按钮、7px 圆角与明暗配色。BM截图/打开阅读器沿用既有查看；HD投屏、摄像头、黑屏、设备策略、维护和敏感标记按钮仅显示「UI 预览，功能尚未接入」的本地提示，不调用新增接口、设备指令或存储。原预览目录、历史快照选择/导出、浮窗重置/关闭、翻译/审计保留在默认折叠的「更多查看」。同设备切换快照保留展开，切设备或账号复位。测试见 `test/device-right-tools.spec.js`，外部 Chrome 验证本机页面。

右栏分组标题显式使用 8px/600、1.2 行高（9.6px），按钮为继承字体的 11px/600、16px 行高；避免 Tabler 的 28px h2 行高扩大标题留白。覆盖仅限该参考组件，更多查看与其他页面字体保持原样；比较截图先统一缩放。上述六轮明暗/宽窄桌面字体与隔离断言沿用同一右栏测试。

详情使用独立 44px 顶栏、110px 左菜单、176px 右工具栏、180px 圆形入口及 300px 浮窗。截图/阅读器保留现有查看流程；右上角密码事件和快捷预览开关各自打开独立的只读空态浮窗，可同时开关；诊断打开通用预览浮窗。固定窗不展示原文、栏目切换或执行按钮。新增栏目由 `/api/devices/:id/ui-preview` 目录驱动，栏目请求显示加载、失败重试和未接入空状态；路由变化取消旧请求。白名单预览动作 POST 的 501 反馈不会显示成功，不发送 WS 指令。历史快照、研究事件、节点、API 调试与备注继续使用既有鉴权接口和合成元数据规则。

相册图片使用 `DeviceGalleryPreview.vue` 主画布空态：左上「获取相册」、透明背景、居中提示，不再打开通用浮窗。按钮仅刷新已有鉴权 gallery GET 的未接入状态，校验设备/栏目/空数组及总数；加载禁用、失败可重试、卸载及账号/设备变化终止旧请求。相册读取与图片数据尚未接入，无真实采集、设备命令或下载。明暗桌面、键盘、无数据/失败/异常与迟到响应回归见 `test/device-gallery-preview.spec.js`。

### 信息页与主画布工具箱

设备信息默认只显示圆形入口与「AI 金融分析」卡。刷新读取 analysis 空态；立即分析提交固定预览动作并显示真实 501 状态。短信缓存及外部 AI 尚未接入，不上传短信内容。按最新要求移除左侧研究记录中的「设备研究信息」「历史快照」「观察记录」三个入口；分组仅保留节点信息、API调试和备注。旧七项元数据在默认展开的「备注」视图中保留，顶栏备注仍可编辑，右侧快照选择/导出及已有快照、事件数据和接口不变。

工具箱使用 `DeviceToolboxPreview.vue` 的五组 112×62px 卡片，仅展示目录中的九个固定预览动作；顶部「模块状态」仍可打开通用 tools 浮窗。目录失败、空态、重试和焦点返回均保留，窄窗口仍为最小 1280px 的横向桌面布局。验证见 `test/device-analysis-toolbox.spec.js` 及两个既有详情预览测试。

### 短信记录与测试数据

### 应用列表、密码记录与备忘录

应用列表采用宽搜索、系统筛选、紧凑分组行与右侧本地预览按钮；密码记录采用应用/类型/关键词过滤和四列表格，内容使用等宽字体。分别由 `DeviceAppsPreview.vue` / `DeviceRecordPreview.vue` 提供，仅 GET 原未接入接口。点击测试数据展示 `src/fixtures/device-apps-demo.json` / `device-records-demo.json` 的八应用/八元数据；不会操作设备或读真实输入。旧五字段观察仍可展开查看，顶部密码事件浮窗保持独立。

「备忘录」由 `DeviceMemosPanel.vue` 复用现有 memos CRUD，支持新增、四标签、编辑、取消、确认删除、刷新与失败重试；旧设备备注保留在顶栏和研究记录内。「应用列表」不再开启通用浮窗。测试见 `test/device-detail-modules.spec.js`，覆盖本地样例筛选、请求契约、切设备取消、真实隔离备忘 CRUD、明暗桌面与窄窗口键盘操作。外部 Chrome 本机联调地址为 `http://127.0.0.1:8083/devices/1`。

密码记录页筛选栏为 160/90/165/52px 四控件、29px 高、8px 间距，数量与来源标记同排显示；表格保持 34px 行与四列，内容使用等宽字体，状态/样例以小标签区分。五字段元数据默认折叠，键盘 Enter/Space 可展开查看。测试数据继续使用原八条合成记录，默认 GET 为空，无设备输入或解锁执行；`test/device-detail-modules.spec.js` 校验明暗主题、1440/1280/800px 横向布局及键盘操作。
