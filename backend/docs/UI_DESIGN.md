# UI 设计与 AI 延续约定

## 设计依据
2026-09-19 用户补充的两张参考图明确了紧凑控制台方向。本项目采用其布局结构、信息密度、配色层级和浮窗交互；保留 Boundary Lab 的品牌、研究语义和明确标注的示例数据。

## 列表页
- 固定顶部：品牌、搜索、在线设备/设备总数、今日/昨日分组统计、本地工作区、主题开关与指南。横向单行对齐，不用快照/节点/观察/协议胶囊替代日期统计区。
- 在线数量及每日安装/离线/无障碍事件尚未接入时显示「—」，悬停与无障碍说明标明未知；设备总数来自当前项目的记录总量（包含示例），不随列表筛选改变。
- 搜索框宽 200–312px，双日统计区宽 304–480px；随桌面画布适度伸缩，统计数值在上、标签在下，日期与指标用细竖线分隔。账号区保留在右侧。
- 窄图标侧栏：桌面基准宽 56px；图标上、文字下。
- 主侧栏仅保留「设备、构建、翻译」三个入口，顺序固定；移除快照、观察、指南侧栏项。已有记录、详情内部视图和页面路由保留。
- 顶栏常规高 46px，大桌面高 50px；第二行工具栏约 40px。
- 表格贴合内容区域边缘，无大卡片外边距；表头约 29px，行高 68px。
- 15 列（含选择、缩略图和操作）；列表移除节点列，最小表格宽 1230px，窄屏横向滚动。
- 行悬停/选择为淡蓝紫色；状态采用小型圆角标签。
- 点击整行进入设备详情；聚焦行后 Enter/空格同样跳转。勾选框、链接、操作按钮与文字选择不触发行导航。
- 操作列仅红色描边「拉黑」与深红色「删除」，均需确认。已拉黑显示「取消拉黑」；操作中禁用按钮防止重复提交。不再显示查看/节点按钮，详情内节点阅读器保留。
- 拉黑停止设备接入并清理实时画面，取消后允许有效设备凭证再次连接。删除是后台软删除：退出列表及正常读取、撤销设备凭证、保留历史审计，不清除手机数据。
- 搜索、筛选、选择当前页、详情、快照与备注入口有实际行为；手动导入入口按用户要求移除。
- 可排序表头显示 ⇅；当前升序显示 ↑、降序显示 ↓。实际在数据库中排序，保留搜索/筛选，切换排序回到第一页。
- 数值按数值排序；缺失记录置末；同值以内部 ID 稳定排序。节点/窗口取最新快照，不取历史最大值。
- 手机形缩略块是合成占位，不表示真实壁纸或采集结果。

## 详情页
- 独立顶部状态条：设备、版本/标识、备注、保存、来源与记录状态。
- 桌面 3 列：左侧菜单 88px + 弹性画布 + 右侧工具栏 148px。
- 中央圆形入口直径约 151px，深色圆心、紫粉渐变描边。
- 圆形入口下为横向概览卡，其余保持留白。
- 左侧菜单切换本机视图：设备信息、快照、短信观察、密码事件、观察记录、节点信息、备注。
- 右侧是已有研究查看操作；不存在的能力不放置可点击的假按钮。

## 截图与阅读器
- 通过 Vue 共享组件 `FloatingViewer` 与 `NodeReader` 渲染。
- 非模态双浮窗，不锁死背景工作台；可单独开启或并排开启。
- 每个浮窗默认宽 **300 CSS px**，用 −/＋按 20px 调整，范围 220–500px；各自独立，无百分比半屏扩展。
- 截图随窗口宽度等比例缩放，移除原来的 100% 滑杆；底部保留查看原图链接。内容超过可见高度时在窗口内滚动。
- 阅读器头部放置翻译/原文、A−、55%、A＋；字号范围 35–100%，步进 5%。仅小浮窗容器在 260px 以下将头部按钮放到第二行，不重排整个桌面。
- 翻译 API 设置通过侧栏「翻译」、右侧工具栏或阅读器设置图标访问。设置页面延续窄导航、白色配置卡与蓝色主操作。
- 未启用、未配置、超时与接口错误明确反馈；成功译文以 textContent 绘制，原文切换不发请求。首次点击翻译只发送预设样例标签，当前没有节点正文采集。
- 默认阅读器显示坐标映射，另有节点树和 JSON 视图。
- 桌面拖动标题栏调整位置；关闭按钮、Esc、关闭全部、重置位置均有行为。
- Esc 关闭最前方窗口；关闭后恢复焦点。节点页签支持左右箭头与 Home/End。
- 窗口位置不持久化；调整浏览器大小后重置，避免窗口遗留屏幕之外。
- 截图是已保存文件或合成样例；阅读器显示结构与固定样例标签，不发送设备操作。标签来源与底部说明保持明确。

## 桌面工作台（按用户最新要求）
- 仅设计桌面工作台，不维护手机版或手机断点。
- 最小画布宽 1280px。窗口更窄时整页横向滚动，保持桌面的栏目、文字尺寸和工具栏位置。
- 详情始终是左菜单、中央画布、右工具栏三列；双浮窗始终并排，宽度保持稳定。
- 顶栏随桌面画布横向滚动，纵向滚动时吸顶；右侧工具栏通过横向滚动访问。
- 浮窗拖动边界以桌面画布为准，不以窄窗口宽度裁切；重置位置和 Esc 保持原有行为。
- 保留大桌面（1800px 以上）的尺寸微调与明暗主题，不引入手机重排。

## 文件职责
- `frontend/src/App.vue`：标准、列表、详情壳布局及账号状态。
- `frontend/src/components/FleetStats.vue`：在线/总数与今日/昨日分组。
- `frontend/src/components/SortHeading.vue`：排序操作、方向与无障碍语义。
- `backend/src/store.js`：服务端排序、分页、项目范围与关联校验。
- `frontend/src/styles/`、`frontend/src/style.css`：延续的桌面 CSS 与 Vue 追加样式。
- `frontend/src/components/ViewerWidth.vue`、`FloatingViewer.vue`：独立宽度、拖动、关闭和焦点。
- `frontend/src/components/NodeReader.vue`：结构、坐标、检索、字号和固定标签翻译。
- `backend/src/translation.js`、`protocol.js`：固定提供商调用、加密配置及样例标签白名单。

## 验收标准
桌面与窄浏览器窗口分别验收；后者确认仍为桌面三列和并排浮窗，并可横向滚动。检查列表搜索、升降序、筛选与分页保持、选择、独立详情跳转、栏目筛选、双浮窗、节点检索、关闭与焦点。保留现有服务端校验与测试，不因视觉改动绕过输入校验或归属检查。


## Vue 迁移对应关系（2026-09-28）

当前 Node 主工作台继续使用上面的桌面布局参数。Vue 复用 `FleetStats`、`SortHeading`、`ViewerWidth`、`FloatingViewer` 和 `NodeReader`。本地 Tabler 与图标位于 frontend/public/vendor；原桌面 CSS 已移入 frontend/src/styles 并由 Vite 打包，旧 Blade 与脚本已移除。页面生命周期由 Vue Router 管理，详情退出自动取消只读 WS 订阅。主侧栏仍仅设备、构建、翻译；档案与审计使用页内链接，不增加侧栏入口。

超管登录页 `/login` 使用紧凑居中表单，不显示设备导航和数据；账号、密码均有可关联标签和自动填充语义。顶栏账号入口显示实际用户名与「超管 · 全部设备」，进入 `/settings/account` 退出或改密。失效/被挤下时移除工作台内容并回到登录。总台和子账号本轮无新增菜单；后续设计见 ACCOUNT_DESIGN.md。

## 构建中心

沿用设置页卡片与 Tabler 表单，桌面三列表单、包名占两列：模板版本/后台域名/APP 名称/HTTPS 首页/APK ID/可选批次/可选包名。随机生成只更新包名，空包名提交后由服务端生成。模板说明展示真实源码目录与 Android 版本，不把版本名当成功能。记录显示真实阶段、错误、下载与复制链接；剪贴板失败展示可选择的 URL，链接需登录。提交禁用重复点击，活动任务两秒刷新、空闲十秒刷新，退出停止轮询。保留页面下方设备登记入口，不打包登记码。
