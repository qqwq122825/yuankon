# UI 设计与 AI 延续约定

## 设计依据

2026-09-19 用户补充的两张参考图明确了紧凑控制台方向。本项目采用其布局结构、信息密度、配色层级和浮窗交互；保留 Boundary Lab 的品牌、研究语义和明确标注的示例数据。

## 列表页

- 固定顶部：品牌、搜索、在线设备/设备总数、今日/昨日分组统计、本地工作区、主题开关与指南。横向单行对齐，不用快照/节点/观察/协议胶囊替代日期统计区。
- 在线数量来自最近 90 秒有效设备连接。今日/昨日按北京时间的设备首次登记时间分组，依次展示安装数、该批设备当前离线数和当前已开启无障碍数；旧数据没有可核对的登记时间时显示「—」。设备总数来自当前项目的未删除记录总量（包含示例），不随列表筛选改变。
- 搜索框宽 200–312px，双日统计区宽 304–480px；随桌面画布适度伸缩，统计数值在上、标签在下，日期与指标用细竖线分隔。账号区保留在右侧。
- 窄图标侧栏：桌面基准宽 56px（大桌面 64px）；图标上、文字下。按 2026-09-28 补充参考固定在浏览器窗口左侧，顶部避让 46px / 50px 顶栏，底部贴视口；纵向滚动或窄窗口横向查看表格时均保持可见。侧栏保留不透明背景与层级，内容默认留出等宽左边距；矮窗口允许侧栏独立纵向滚动。详情页继续使用独立布局，不叠加主侧栏。
- 主侧栏仅保留「设备、构建、翻译、日志」四个入口，顺序固定；日志展示客户端 HTTP 与设备 WebSocket 请求元数据。移除快照、观察、指南侧栏项，设备列表底部分页区也不放快照档案、观察记录链接；已有记录、详情内部视图和页面路由保留。
- 顶栏常规高 46px，大桌面高 50px；第二行工具栏约 40px。
- 表格贴合内容区域边缘，无大卡片外边距；表头约 29px，行高 68px。
- 列顺序按参考图固定为：选择、ID、壁纸、账号、备注、备忘、应用、品牌、版本、APK、地区、网络、密码、电池、在线、屏幕、无障碍、注入、AI、安装时间、延迟、操作；最小表格宽 2070px，窄屏横向滚动。当前未采集的地区、网络、密码、注入、AI 与延迟显示「—」，不放置虚假数据或装饰排序箭头。
- 行悬停/选择为淡蓝紫色；状态采用小型圆角标签。
- 点击整行进入设备详情；聚焦行后 Enter/空格同样跳转。勾选框、链接、操作按钮与文字选择不触发行导航。
- 操作列仅红色描边「拉黑」与深红色「删除」，均需确认。已拉黑显示「取消拉黑」；操作中禁用按钮防止重复提交。不再显示查看/节点按钮，详情内节点阅读器保留。
- 拉黑停止设备接入并清理实时画面，取消后允许有效设备凭证再次连接。删除是后台软删除：退出列表及正常读取、撤销设备凭证、保留历史审计，不清除手机数据。
- 搜索、筛选、选择当前页、详情、快照、备注与备忘入口有实际行为；手动导入入口按用户要求移除。列表备注列显示现有备注或「点击备注」，点击后在原单元格切换为单行输入框，Enter/失焦保存、Esc 取消且不触发行跳转。备注是设备的单值说明；备忘列保持独立入口，管理多条记录并支持无标签/重要/待跟进/已处理以及新增、编辑、删除。
- 可排序表头显示 ⇅；当前升序显示 ↑、降序显示 ↓。实际在数据库中排序，保留搜索/筛选，切换排序回到第一页。
- 数值按数值排序；缺失记录置末；同值以内部 ID 稳定排序。节点/窗口取最新快照，不取历史最大值。
- API 设备有有效首图时，壁纸列显示当前内存缩略图；无首图及合成记录使用明确的记录/示例占位，不把占位当成真机画面。
- 安装时间取不可变的首次登记时间，按北京时间显示 `MM-DD HH:mm:ss`。自动上线续签、飞行模式恢复、进程重连和后续截图均不得刷新该时间；升级迁移会优先用已有首次登记审计修复旧版本反复续写的时间。

## 详情页

- 独立顶部状态条：设备、版本/标识、备注、保存、来源与记录状态。
- 桌面 3 列：左侧菜单 88px + 弹性画布 + 右侧工具栏 148px。
- 中央圆形入口直径约 151px，深色圆心、紫粉渐变描边。
- 圆形入口下为横向概览卡，其余保持留白。
- 左侧菜单切换本机视图：设备信息、快照、短信观察、密码事件、观察记录、节点信息、备注。
- 右侧是已有研究查看操作；不存在的能力不放置可点击的假按钮。

## 截图与阅读器

- 通过 Vue 共享组件 `FloatingViewer` 与 `NodeReader` 渲染。
- 非模态双浮窗，不锁死背景工作台；可单独开启或并排开启。
- 截图与实时 BM 截图浮窗固定宽 **300 CSS px**，不显示缩放控件；阅读器默认宽 300px，并可用 −/＋按 20px 在 220–500px 范围内独立调整。实时截图画布默认按手机 9:16 预留高度，首帧到达后锁定该帧宽高比，刷新或短暂无图时不收缩。
- 实时截图浮窗标题栏显示本次查看已接收的去重截图序号；重复轮询同一帧不增加计数。
- 实时画面下方固定一排返回、Home、多任务、锁屏、点亮和勿扰按键；按键只在设备在线且查看租约有效时可用。勿扰的“已开启/已关闭”浮层以设备 ACK 为准，不在点击时假设成功。
- 截图随窗口宽度等比例缩放，移除原来的 100% 滑杆；底部保留查看原图链接。内容超过可见高度时在窗口内滚动。
- 阅读器头部放置翻译/原文、A−、55%、A＋；字号范围 35–100%，步进 5%。仅小浮窗容器在 260px 以下将头部按钮放到第二行，不重排整个桌面。
- 翻译 API 设置通过侧栏「翻译」、右侧工具栏或阅读器设置图标访问。设置页面延续窄导航、白色配置卡与蓝色主操作。
- 未启用、未配置、超时与接口错误明确反馈；成功译文以 textContent 绘制，原文切换不发请求。首次点击翻译只发送预设样例标签，当前没有节点正文采集。
- 阅读器只显示默认坐标映射，不显示坐标/节点树/JSON 页签或搜索框。API 设备在有效查看租约内使用实时模式：300px 宽屏幕比例容器内按百分比绘制节点边框，点击节点可查看该节点的结构字段；结构未到达时仍保留可用高度，不发生坍塌。
- 实时模式默认显示固定中文角色标签；“原文”切回 Android 类名，不调用外部翻译。A−/A＋ 仅调整标签字号，宽度仍由独立的 220–500px 控件调整。两个实时浮窗底部固定显示返回、Home、多任务、锁屏、点亮和勿扰操作，并各自保留一行文本输入与蓝色「发送」按钮；截图框提示“输入文本…”，阅读器提示“输入或粘贴文本…”。
- 桌面拖动标题栏调整位置；关闭按钮、Esc、关闭全部、重置位置均有行为。
- Esc 关闭最前方窗口；关闭后恢复焦点。
- 窗口位置不持久化；调整浏览器大小后重置，避免窗口遗留屏幕之外。
- 合成/历史设备的截图仍是已保存文件或合成样例。已登记 API 设备的圆形「开始」入口和「实时查看截图」同时打开 BM 截图与阅读器：每 5 秒续租，两个浮窗都关闭/网页离开后结束租约、设备循环、快捷操作与焦点文本发送。截图只保留最新图且最多暂存 5 分钟；节点只保留当前 viewerId 的内存结构，正文固定省略，并在租约结束时清理。

## 桌面工作台（按用户最新要求）

- 仅设计桌面工作台，不维护手机版或手机断点。
- 最小画布宽 1280px。窗口更窄时整页横向滚动，保持桌面的栏目、文字尺寸和工具栏位置。
- 详情始终是左菜单、中央画布、右工具栏三列；双浮窗始终并排，宽度保持稳定。
- 顶栏随桌面画布横向滚动，纵向滚动时吸顶；右侧工具栏通过横向滚动访问。
- 浮窗拖动边界以整个桌面画布为准，可到达浏览器内容区域左边缘与顶边 `0px`，不再被顶栏或左菜单留白限制；窄窗口不裁切桌面画布，重置位置和 Esc 保持原有行为。
- 保留大桌面（1800px 以上）的尺寸微调与明暗主题，不引入手机重排。

## 文件职责

- `frontend/src/App.vue`：标准、列表、详情壳布局及账号状态。
- `frontend/src/components/FleetStats.vue`：在线/总数与今日/昨日分组。
- `frontend/src/components/SortHeading.vue`：排序操作、方向与无障碍语义。
- `backend/src/store.js`：服务端排序、分页、项目范围与关联校验。
- `frontend/src/styles/`、`frontend/src/style.css`：延续的桌面 CSS 与 Vue 追加样式。
- `frontend/src/components/ViewerWidth.vue`、`FloatingViewer.vue`：阅读器独立调宽，截图固定 300px；浮窗支持拖动、关闭和焦点。
- `frontend/src/components/NodeReader.vue`：默认坐标预览、字号和固定标签翻译；不显示节点视图页签与搜索，选择坐标节点后展示该节点全部已上报结构字段，并明确标记本帧是否截断。实时帧更新时保留仍存在的选中节点。节点正文与输入内容继续不采集。
- `backend/src/translation.js`、`protocol.js`：固定提供商调用、加密配置及样例标签白名单。

## 验收标准

桌面与窄浏览器窗口分别验收；后者确认仍为桌面三列和并排浮窗，并可横向滚动。检查列表搜索、升降序、筛选与分页保持、选择、独立详情跳转、栏目筛选、双浮窗、坐标节点选择、关闭与焦点。保留现有服务端校验与测试，不因视觉改动绕过输入校验或归属检查。

## Vue 迁移对应关系（2026-09-28）

当前 Node 主工作台继续使用上面的桌面布局参数。Vue 复用 `FleetStats`、`SortHeading`、`ViewerWidth`、`FloatingViewer` 和 `NodeReader`。本地 Tabler 与图标位于 frontend/public/vendor；原桌面 CSS 已移入 frontend/src/styles 并由 Vite 打包，旧 Blade 与脚本已移除。页面生命周期由 Vue Router 管理，详情退出自动取消只读 WS 订阅。主侧栏为设备、构建、翻译、日志；日志页展示最近 7 天客户端 HTTP 和设备 WebSocket 元数据，不保存正文或凭证。快照与观察页继续保留路由，但不出现在主导航或设备列表分页区。

一次性安装页 `/install` 与超管登录页 `/login` 使用紧凑居中表单，不显示设备导航和数据。未安装时所有页面跳转 `/install`，表单收集超管账号、密码与确认密码；成功后入口锁定并跳转登录。账号、密码均有可关联标签和自动填充语义。顶栏账号卡按 2026-09-28 参考图采用圆角浅底、字母头像、双行身份信息与右侧有效期徽标：实际用户名、「角色 · APK ID」、长期有效或到期日期。ID 取 accounts.apk_id 单一固定编号，在账号创建时自动分配；初始超管编号为 `1`，不显示历史别名或 +N；不套用参考图的账号/日期。头像 28px，卡片 218–320px，长名称/ID 截断并保留完整 title；不挤掉原顶栏分组，窄窗口继续横向滚动。正常/即将到期/已到期使用绿/橙/红色并带文字区分，深色主题保持对比。整卡为可键盘访问的账号设置链接，进入 `/settings/account` 查看固定 ID、有效期、退出或改密。失效/被挤下时移除工作台内容并回到登录。总台和子账号本轮无新增菜单；有效期与续费设计见 ACCOUNT_DESIGN.md。

## 构建中心

沿用设置页卡片与 Tabler 表单，桌面并排显示两个构建板块。左侧“第 1 步”是 B 包工作端，可选择登记的 B 包版本并填写后台域名、APP 名称、可选 APK ID/批次/包名；B 包不显示或接收首页地址，无障碍服务名称与构建时 APP 名称相同。右侧“第 2 步”是 A 包安装器，可选择 A 包版本，填写名称、HTTPS 首页地址和包名，并显示将携带的最新成功 B 包 ID、包名与摘要。A 包 1.2 在手机上检测到 B 包未安装时只显示「安装 B 包」；本次安装成功返回后显示无障碍说明。Android 13 及以上先提供「打开 B 包应用信息」，供用户在系统右上角菜单选择「允许受限设置」，随后再进入无障碍页面；启用同名 B 包服务并返回后显示内置浏览器首页。完成首次引导后，检测到已安装时直接显示首页。A 包不显示独立「打开首页」或「打开 B 包设置」按钮，B 包没有 Activity 或桌面入口。没有 B 包时禁用 A 包按钮。随机生成只更新对应表单包名，空包名提交后由服务端生成。记录用 A 包/B 包/独立包标签区分；A 包行显示内置 B 包 ID 和包名。记录按 queued、preparing、compiling、signing、aligning、inspecting、publishing、succeeded/failed 显示阶段进度条、真实状态、错误、下载与复制链接；点击「构建日志」在当前记录下方展开鉴权文本日志，不触发下载，活动构建每两秒自动刷新并滚动到最新输出，也可手动刷新或收起。剪贴板失败展示可选择的 URL；产物链接以随机 UUID 标识并可直接分享，日志与管理接口仍需登录。提交禁用重复点击，活动任务两秒刷新、空闲十秒刷新，退出停止轮询。APK ID 留空或未匹配可用账号时使用默认接收账号；提交回执与记录显示实际编号、接收账号及匹配原因。移除构建页和账号设置中的手动登记区域；当前 B 包按构建写入的 APK ID 自动归属上线。

## 2026-09-30 列表工具栏与本地快捷筛选

- 工具栏固定单行：当前设备、刷新状态、清除筛选、即时筛选说明、筛选按钮。最小画布维持 1280px，空间不足时横向滚动，按钮不另起一行；工具栏 50px、按钮与筛选 34px，表头 36px、数据行 85px。
- 在线/离线、无障碍、来源快捷筛选使用页面内缓存，只更新 URL 和本地视图，不发起设备列表 HTTP 请求或设备 WS 命令。翻页也使用缓存；搜索、字段排序仍由 SQL 服务端执行。
- 进入列表、手动刷新、设备状态变化时加载缓存。API 默认每页 10 条不变；页面以经验证的 `perPage=500` 分批预加载当前搜索和排序下的全部行，所以在线筛选不会漏掉第二页以后的设备。每次刷新替换缓存，离开页面清空；不跨账号持久化。并发旧请求通过 AbortController 取消。
- 本地筛选后重新计算数量/页数，选择当前页只选择可见设备；未知无障碍状态不算“未开”。组合筛选、取消筛选、浏览器前进/后退都使用同一缓存。
- 未接入的地区、网络、密码、注入、AI、列表延迟保留空单元格；不增加参考图中尚未实现的按钮或伪统计。真实数据缺失仍区分为未知，不从样例推断在线。

## 2026-09-30 参考站实测对齐

读取用户已登录参考设备页的 DevTools 与 DOM 计算样式，按照 CSS 像素而非截图像素校准（参考浏览器缩放 80%）。顶栏 58px、搜索 32px、统计分组 38px；工具栏 50px，所有按钮/筛选 34px，刷新主色 #4658d9；表头 36px/11px 字体、行高 85px/13px 字体、单元格左右 14px。大屏不再缩小表格字体。无临时截图时使用 36×64px 中性手机占位，真实缩略图继续展示，不用随机渐变伪装壁纸。在线为圆点+文字，无障碍为浅绿小标签。

保留本项目品牌、四个主菜单、56/64px 固定侧栏、1280px 最小画布、现有服务端排序和鉴权。详情页尺寸不变。不添加参考站未接入的菜单或伪按钮；六个未接入列仍为空。快捷筛选继续仅使用缓存，浏览器回退、组合筛选与键盘操作均不发送请求或手机命令。

本地隔离预览使用 127.0.0.1:8082、临时数据库和明确标注的合成设备，不改现有数据库或线上部署。覆盖 1837×905 的参考视口、1440、1280、800 的桌面横向滚动与深色主题。
