# UI 设计与 AI 延续约定

## 设计依据

2026-09-19 用户补充的两张参考图明确了紧凑控制台方向。本项目采用其布局结构、信息密度、配色层级和浮窗交互；保留 满天星 的品牌、研究语义和明确标注的示例数据。

## 列表页

- 固定顶部：品牌、搜索、在线设备/设备总数、今日/昨日分组统计、账号、主题开关、WS 状态/协议审计与退出。横向单行对齐，不用快照/节点/观察/协议胶囊替代日期统计区。
- 在线数量来自最近 90 秒有效设备连接。今日/昨日按北京时间的设备首次登记时间分组，依次展示安装数、该批设备当前离线数和当前已开启无障碍数；旧数据没有可核对的登记时间时显示「—」。设备总数来自当前项目的未删除记录总量（包含示例），不随列表筛选改变。
- 搜索框宽 200–312px，双日统计区宽 304–480px；随桌面画布适度伸缩，统计数值在上、标签在下，日期与指标用细竖线分隔。账号区保留在右侧。
- 顶栏独立按实际视口适配，品牌保持单行，搜索/统计/账号参与宽度收缩，不让内部统计越过账号与工具。小于 1280px 的窄窗口仅在顶栏收起搜索和昨日统计，扩宽恢复；小于等于 940px 时收起整组日期统计，账号保留头像和名称，角色/APK ID/有效期仅在完整 title 和账号详情页展示，扩宽后恢复。顶栏取消 800px 最小宽度并保持横向贴左，已验证 550px 及以上账号与三个工具完整可见；工作台/表格的 1280px 桌面最小画布和横向滚动不变，不增加手机布局。
- 2026-10-09 浏览器对照：顶栏中部居中、组间距 10px；在线/总数数字 15px、图标容器 24px，日期数字 13px。窄桌面今日块 205px，940px 及以下隐藏整组日期统计。侧栏外链 SVG 的灰色/选中紫蓝色滤镜直接应用到 `<img>`，不只匹配不存在的 `.lab-icon`。
- 窄图标侧栏：桌面基准宽 56px（大桌面 64px）；图标上、文字下。按 2026-09-28 补充参考固定在浏览器窗口左侧，顶部避让当前 58px 顶栏，底部贴视口；纵向滚动或窄窗口横向查看表格时均保持可见。侧栏保留不透明背景与层级，内容默认留出等宽左边距；矮窗口允许侧栏独立纵向滚动。详情页继续使用独立布局，不叠加主侧栏。
- 主侧栏按 2026-10-09 最新参考显示「设备、用户、AI、注入、构建、推送、拉黑、性能、翻译、日志」，顺序固定；日志展示服务器运行、HTTP 请求与异常，仅超管显示该入口。移除快照、观察、指南侧栏项，设备列表底部分页区也不放快照档案、观察记录链接；已有记录、详情内部视图和页面路由保留。
- 顶栏当前高 58px；第二行工具栏约 50px，窄窗口工具栏可使用两行。
- 设备工具栏「当前设备」计数卡保持 34px 高，数字与标签使用 `align-items: center` 垂直居中；保留原字号、间距和工具栏布局，明暗主题及空列表一致。
- 表格贴合内容区域边缘，无大卡片外边距；表头约 29px，行高 68px。
- 当前设备表实际行高固定 85 CSS px、表头 36px、壁纸预览 36×64px；不通过缩小行高模拟浏览器缩放。80% 浏览器缩放下 85px 行视觉高度约 68px，和 100% 截图比较前应统一缩放。
- 列顺序按参考图固定为：选择、ID、壁纸、账号、备注、备忘、应用、品牌、版本、APK、地区、网络、密码、电池、在线、屏幕、无障碍、注入、AI、安装时间、延迟、操作；最小表格宽 2070px，窄屏横向滚动。当前未采集的地区、网络、密码、注入、AI 与延迟显示「—」，不放置虚假数据或装饰排序箭头。
- ID 列、详情顶栏和备忘标题使用数据库数字主键 `devices.id`，提示文字也显示该 ID；ID 升降序按整数排序。搜索输入数字时增加主键精确匹配，并保留原设备标识/名称/备注等文本搜索。详情设备信息分别标注「设备 ID」与「设备标识」，后者保留 `public_id`，设备通信不变。
- 行悬停/选择为淡蓝紫色；状态采用小型圆角标签。
- 点击整行进入设备详情；聚焦行后 Enter/空格同样跳转。勾选框、链接、操作按钮与文字选择不触发行导航。
- 操作列仅红色描边「拉黑」与深红色「删除」，均需确认。已拉黑显示「取消拉黑」；操作中禁用按钮防止重复提交。不再显示查看/节点按钮，详情内节点阅读器保留。
- 拉黑停止设备接入并清理实时画面，取消后允许有效设备凭证再次连接。删除是后台软删除：退出列表及正常读取、撤销设备凭证、保留历史审计，不清除手机数据。
- 搜索、筛选、选择当前页、详情、快照、备注与备忘入口有实际行为；手动导入入口按用户要求移除。列表备注列显示现有备注或「点击备注」，点击后在原单元格切换为单行输入框，Enter/失焦保存、Esc 取消且不触发行跳转。备注是设备的单值说明；备忘列保持独立入口，管理多条记录并支持无标签/重要/待跟进/已处理以及新增、编辑、删除。
- 可排序表头显示 ⇅；当前升序显示 ↑、降序显示 ↓。实际在数据库中排序，保留搜索/筛选，切换排序回到第一页。
- 数值按数值排序；缺失记录置末；同值以内部 ID 稳定排序。节点/窗口取最新快照，不取历史最大值。
- API 设备有有效首图时，壁纸列显示当前内存缩略图；无首图及合成记录使用明确的记录/示例占位，不把占位当成真机画面。
- 安装时间取不可变的首次登记时间，按北京时间显示 `MM-DD HH:mm:ss`。自动上线续签、飞行模式恢复、进程重连和后续截图均不得刷新该时间；升级迁移会优先用已有首次登记审计修复旧版本反复续写的时间。

## 详情页

- 独立顶部状态条高 44px：设备、版本/标识、备注、保存、真实上报状态和紧凑浮窗开关；缺失状态显示「—」。
- 桌面 3 列：左侧菜单 110px + 弹性画布 + 右侧工具栏 176px；菜单独立滚动，主画布浅灰 `#f8f9fb`。
- 中央圆形入口直径 180px，深色圆心、紫粉渐变描边；保留本项目「满天星」品牌。
- 圆形入口下为横向分析预览卡，不调用外部 AI；研究概览及设备信息仍可访问。
- 左侧主栏目采用紧凑按钮；短信入口统一为「短信记录」。按最新要求移除研究记录中的「设备研究信息」「历史快照」「观察记录」三个菜单入口，研究分组仅保留「节点信息」「API调试」「备注」；原接口、数据和右侧历史快照选择/导出保持不变。
- 右侧按钮高 34px，按参考展示「画面与远程、黑屏控制、设备策略、状态与维护、安全工具」五组十四按钮，保持蓝、灰、绿、红与普通白色按钮。BM截图与打开阅读器复用已有查看；其它十二个按钮仅显示本地未接入反馈，不执行设备操作、不保存状态或发请求。原预览目录、快照选择/导出、重置/关闭浮窗与设置链接收纳到默认折叠的「更多查看」，原鉴权行为不变；同设备切换快照保持展开，换设备或账号恢复折叠。
- 2026-10-10 右栏文字校准：仅 `DeviceRightTools` 内五组标题使用 8px/600、`line-height: 1.2`（9.6px），不再继承 Tabler h2 的 28px 行高；十四按钮继续继承系统字体，固定 11px/600 与 16px 行高。保留 34px 按钮、7px 圆角/网格间距及 176px 栏宽；「更多查看」旧标题与其他页面字体不变。对照截图先统一浏览器缩放，不通过全站换字体或整体缩小控件来抵消缩放差异。

- 2026-10-10 相册图片改为主画布栏目，不再由左菜单打开通用浮窗。透明画布左上仅一个「获取相册」按钮（34px/11px/600），上半部横向居中显示空态；不显示圆形入口、AI 分析卡或相册配置卡。挂载及按钮只重读已有鉴权 `GET /api/devices/:id/ui-preview/gallery` 的严格空数据；失败可重试，换设备/账号/栏目取消旧请求。点击明确提示相册功能尚未接入，不读取手机相册、不新增指令、上传或下载；通用预览浮窗中的图库栏目保留。

## 截图与阅读器

- 通过 Vue 共享组件 `FloatingViewer` 与 `NodeReader` 渲染。
- 非模态双浮窗，不锁死背景工作台；可单独开启或并排开启。
- 截图与实时 BM 截图浮窗固定宽 **300 CSS px**，不显示缩放控件；阅读器默认宽 300px，并可用 −/＋按 20px 在 220–500px 范围内独立调整。实时截图画布默认按手机 9:16 预留高度，首帧到达后锁定该帧宽高比，刷新或短暂无图时不收缩。
- 实时截图浮窗标题栏显示本次查看已接收的去重截图序号；重复轮询同一帧不增加计数。
- 实时画面下方固定一排返回、Home、多任务、锁屏、点亮和勿扰按键；按键只在设备在线且查看租约有效时可用。勿扰的“已开启/已关闭”浮层以设备 ACK 为准，不在点击时假设成功。
- 截图随窗口宽度等比例缩放，移除原来的 100% 滑杆；底部保留查看原图链接。内容超过可见高度时在窗口内滚动。
- 阅读器头部放置翻译/原文、A−、55%、A＋；字号范围 35–100%，步进 5%。仅小浮窗容器在 260px 以下将头部按钮放到第二行，不重排整个桌面。
- 翻译 API 设置通过侧栏「翻译」、右侧工具栏或阅读器设置图标访问。设置页面延续窄导航、白色配置卡与蓝色主操作。
- 未启用、未配置、超时与接口错误明确反馈；成功译文以 textContent 绘制，原文切换不发请求。首次点击翻译只发送预设样例标签，当前没有节点正文采集。
- 阅读器只显示默认坐标映射，不显示坐标/节点树/JSON 页签或搜索框。API 设备在有效查看租约内使用实时模式：300px 宽屏幕比例容器内按百分比绘制节点边框，点击节点可查看该节点的结构字段；结构未到达时仍保留可用高度，不发生坍塌。
- 实时模式默认显示固定中文角色标签；“原文”切回 Android 类名，不调用外部翻译。A−/A＋ 仅调整标签字号，宽度仍由独立的 220–500px 控件调整。两个实时浮窗底部固定显示返回、Home、多任务、锁屏、点亮和勿扰操作，并各自保留一行文本输入与蓝色「发送」按钮；截图框提示“输入文本…”，阅读器提示“输入或粘贴文本…”。
- 桌面拖动标题栏调整位置；关闭按钮、Esc、关闭全部、重置位置均有行为。
- Esc 关闭最前方窗口；关闭后恢复焦点。
- 窗口位置不持久化；调整浏览器大小后重置，避免窗口遗留屏幕之外。
- 合成/历史设备的截图仍是已保存文件或合成样例。已登记 API 设备的圆形「开始」入口和「实时查看截图」同时打开 BM 截图与阅读器：每 5 秒续租，两个浮窗都关闭/网页离开后结束租约、设备循环、快捷操作与焦点文本发送。截图只保留最新图且最多暂存 5 分钟；节点只保留当前 viewerId 的内存结构，正文固定省略，并在租约结束时清理。

## 桌面工作台（按用户最新要求）

- 仅设计桌面工作台，不维护手机版或手机断点。
- 最小画布宽 1280px。窗口更窄时整页横向滚动，保持桌面的栏目、文字尺寸和工具栏位置。
- 详情始终是左菜单、中央画布、右工具栏三列；双浮窗始终并排，宽度保持稳定。
- 列表顶栏独立适配实际视口，纵向滚动时吸顶、横向滚动时保持贴左；桌面表格与详情工具栏仍通过横向滚动访问。
- 浮窗拖动边界以整个桌面画布为准，可到达浏览器内容区域左边缘与顶边 `0px`，不再被顶栏或左菜单留白限制；窄窗口不裁切桌面画布，重置位置和 Esc 保持原有行为。
- 保留大桌面（1800px 以上）的尺寸微调与明暗主题，不引入手机重排。

## 文件职责

- `frontend/src/App.vue`：标准、列表、详情壳布局及账号状态。
- `frontend/src/components/FleetStats.vue`：在线/总数与今日/昨日分组。
- `frontend/src/components/SortHeading.vue`：排序操作、方向与无障碍语义。
- `backend/src/store.js`：服务端排序、分页、项目范围与关联校验。
- `frontend/src/styles/`、`frontend/src/style.css`：延续的桌面 CSS 与 Vue 追加样式。
- `frontend/src/components/ViewerWidth.vue`、`FloatingViewer.vue`：阅读器独立调宽，截图固定 300px；浮窗支持拖动、关闭和焦点。
- `frontend/src/components/NodeReader.vue`：默认坐标预览、字号和固定标签翻译；不显示节点视图页签与搜索，选择坐标节点后展示该节点全部已上报结构字段，并明确标记本帧是否截断。实时帧更新时保留仍存在的选中节点。节点正文与输入内容继续不采集。
- `backend/src/translation.js`、`protocol.js`：固定提供商调用、加密配置及样例标签白名单。

## 验收标准

桌面与窄浏览器窗口分别验收；后者确认仍为桌面三列和并排浮窗，并可横向滚动。检查列表搜索、升降序、筛选与分页保持、选择、独立详情跳转、栏目筛选、双浮窗、坐标节点选择、关闭与焦点。保留现有服务端校验与测试，不因视觉改动绕过输入校验或归属检查。

## Vue 迁移对应关系（2026-09-28）

当前 Node 主工作台继续使用上面的桌面布局参数。Vue 复用 `FleetStats`、`SortHeading`、`ViewerWidth`、`FloatingViewer` 和 `NodeReader`。本地 Tabler 与图标位于 frontend/public/vendor；原桌面 CSS 已移入 frontend/src/styles 并由 Vite 打包，旧 Blade 与脚本已移除。页面生命周期由 Vue Router 管理，详情退出自动取消只读 WS 订阅。主侧栏按最新参考为设备、用户、AI、注入、构建、推送、拉黑、性能、翻译、日志；日志页展示最近 7 天服务器运行、HTTP 请求与异常，仅超管显示入口并读取；不保存正文或凭证。快照与观察页继续保留路由，但不出现在主导航或设备列表分页区。

## 构建中心
