# 超管服务器日志

2026-10-05 按用户要求，主导航「日志」改为 `/logs` 服务器日志页，不再显示设备协议日志。Android、无障碍服务、设备诊断和既有协议记录保持原样。

## 已实现

- 独立 `server_logs` 表，服务初始化、开始监听、启动失败、正常停止，以及本 Node 服务的 HTTP 请求、拒绝和处理异常；各项目事件汇总给超管，不按单台设备展示。
- 时间、信息/警告/错误级别、服务运行/HTTP 分类、事件、路由模板、响应状态、耗时，以及固定异常类型/错误码。页面不显示设备列。
- 默认最近 100 条按 ID 升序显示；每 3 秒可增量读取，页面最多 500 条。支持手动刷新、级别/分类筛选、今日 UTC JSONL 导出（最多 10000 条，沿用当前筛选）。
- 前端仅超管显示「日志」和协议审计链接；直接打开 `/logs` 或 `/protocol` 时路由校验角色。后端所有服务器/协议日志列表、增量与导出接口独立检查认证后的超管角色，不依赖前端隐藏。账号认证本身仍沿用现有 Passport/JWT。
- 增量迁移 `016_server_logs` 只新增表；不清除设备、旧协议日志、模板或私有文件。日志从更新后开始生成。

## 数据与运行

日志存放在 `backend/.node-private/boundary.sqlite`，不公开静态目录。保留 7 天，每小时及每 100 次写入清理过期/超出 50000 条的旧记录（两个清理周期之间最多额外 99 条）；待写队列上限 1000 项，溢出不阻塞业务请求。日志写入失败仅向进程 stderr 输出固定提示，不回显数据库或凭证。

HTTP 日志只保存服务端固定路由模板，不存实际路径参数、未知路径、URL 查询、请求头/正文、响应正文、密码、Cookie、JWT、节点文本、截图或原始错误消息/堆栈。成功的静态资源和日志读取请求不记录，避免轮询自产生日志；被拒绝的日志请求仍记录警告。

此页面的来源是 **本 Node 服务**，不伪装成操作系统、宝塔、Nginx 或整台机器其他进程的日志汇总。进程被强制终止、Node 初始化前失败等情况仍从现有进程管理器 stdout/stderr 排查；APK Gradle/Lint 明细仍在构建页的构建日志中。服务器全系统日志采集尚未接入。

## 测试与回退

后端测试覆盖增量迁移、原日志保留、超管读取、未登录拒绝、普通角色防绕过、敏感字段排除、服务异常、最近/增量读取、筛选、日期校验、导出、保留期/数量上限和正常停止。浏览器测试覆盖桌面与窄窗横向滚动、键盘刷新、导出、无数据/接口失败、普通角色入口隐藏与深链跳转；普通角色使用测试夹具，不代表已实现普通账号开通。

运行 `npm run check` 和 `npm run test:e2e`。生产部署仍需用户明确要求，并沿用 [部署手册](DEPLOYMENT.md)；本次本地修改不自动提交、推送或重启线上服务。回退只还原本次代码，保留新增表和数据；旧版本忽略新增表即可，禁止删除数据库或 Android 模板。
